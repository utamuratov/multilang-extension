FormLingo
Translate Inputs Instantly
A lightweight developer tool for multilingual forms. Add data-translate to any input — FormLingo handles the rest.
How it works
1
Add data-translate="langCode" to your inputs or textareas
2
A 🌐 button appears inside each field automatically
3
Type in one field, click the button — all other fields are translated instantly
Basic usage
<!-- Simple: one group --> <input data-translate="en" /> <input data-translate="ru" /> <input data-translate="uz" /> <input data-translate="kk" />
Grouped fields
Use data-formlingo-field to isolate translation groups — each group translates independently.
<!-- Group: "name" --> <input data-translate="en" data-formlingo-field="name" /> <input data-translate="ru" data-formlingo-field="name" /> <!-- Group: "description" --> <textarea data-translate="en" data-formlingo-field="description"></textarea> <textarea data-translate="ru" data-formlingo-field="description"></textarea>
